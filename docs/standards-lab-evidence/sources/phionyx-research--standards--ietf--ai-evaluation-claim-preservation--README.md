# draft-abak-ai-evaluation-claim-preservation — public work area

This is the public work area for the individual Internet-Draft
**draft-abak-ai-evaluation-claim-preservation**, “Claim-Preserving Exchange of
AI Evaluation Evidence.” Revision `-00` was posted on **23 September 2026** with
an **Informational target**.

## Status boundary

- This is an individual Internet-Draft. It is **not WG-adopted**, is **not IETF
  consensus**, and is **not an IETF-endorsed standard**.
- Publication of `-00` implies **no implementation or interoperability result**.
- AIREP is informative related work, **not a normative dependency**.
- This directory must never present draft publication as adoption.
- The immutable published baseline is the exact IETF archive copy under
  [`draft/published/00/`](draft/published/00/). Commentary in this directory
  does not replace or amend those files.

## Scope

The draft defines format-neutral requirements for preserving result selection,
execution and measurement state, criteria, coverage, and material
qualifications as AI evaluation evidence moves between tools and administrative
domains. It states twelve preservation requirements and twenty mapping test
scenarios.

It does not define a new wire format, benchmark, frontier threshold, evaluator
or safety certification, authorization or control protocol, or cryptographic
envelope. The mapping scenarios are a review instrument, not a report of an
executed conformance suite.

## Relationship to AIREP

The AIREP Embedded Evaluation Profile 0.1 is cited as an informative example of
related work. The draft is broader and format-neutral: it does not depend on
AIREP, revise AIREP, change AIREP conformance, or establish AIREP adoption or
standardization.
