# External evidence methodology

This delivery packages frozen K2 `ea1f39a6da72639a73e601918a6c8bc87bff1d77`
and K3 `76ecce0b378a6b391850795abf45fb6aca8e1d6b`. The latter includes D
`0130fcf8e7d70a0f9c4f977957e5de76ca8ef689`. They are separate source lanes.
The K2 execution target is release commit
`8a6c01ecce457aa94330c0ed7219e4c56ebfe771`, not whichever source is newest.
K3 uses its own exact implementation/normative pins. A shared beta label does
not make executable source revisions identical.

An unrelated researcher can reproduce the author's reference results immediately
from the distributed packet. There is no sealed private oracle for these two
lanes: positive/negative inputs and their published interpretations are available
in the bundled source. No delayed reveal or private invitation is needed.
This is not a new blind experiment. If a future lane needs delayed reveal,
publish its input manifest/commitment, technically isolate the solver from
answers/history, freeze the solver before reveal, then publish the committed
answer envelope and a mechanical comparator. Such future work is PENDING here.

The runner labels every invocation AUTHOR_SIDE_REFERENCE by default because it
cannot know who is running it. An outside rerunner may submit attributable
evidence for later EXTERNAL_REPRODUCTION assessment. It never edits that
classification, opens an issue, or counts participation automatically.

Retain original native outputs. Projection agreement/divergence is a comparison
of reported fields; it is not conformance, independent authorship, event truth,
authority validity, enforcement, causal effect, or complete population coverage.
Malformed mapped output is a transport/adapter error. Missing mapping stays
NOT_COMPARABLE. Unavailable native predicates stay NOT_EVALUATED. The packet adds
no wire field, fifth artifact family, assurance class, or acceptance rule.

An external submission is assessed in stages: receipt; byte/source/role checks;
reproduction attempt; scope and independence assessment; explicit permission to
cite; then a human decision on accepted evidence classification. Keep each
stage's failures or unresolved facts. Never infer project acceptance from a
successful local rerun. A citation/acknowledgement remains a separate event.

The current local clean-room validation, when recorded, establishes packaging
and replay availability on the documented system axis. It is owner-controlled,
not a third-party replication. The methodology does not require paid LLM calls.
